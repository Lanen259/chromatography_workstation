## 2. 结论状态规则（本 Phase 特有）

- **✅ 源码确认**：读到该文件该方法的实际实现（贴关键行）。
- **⚠️ 根据代码推测**：从相邻实现/调用关系推出，但未直接读到算法主体。
- **⚠️ 背景假设**：仅基于领域常识或历史，尚未进源码。
- **❌ 禁止**：把推测写成确认；禁止无出处地描述"OpenChrom 有峰检测"。
