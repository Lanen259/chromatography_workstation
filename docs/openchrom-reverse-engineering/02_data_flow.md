## 1. 数据流主线（必查链路）

```text
Input File (*.mzML / *.netCDF / *.ANDI-MS / *.CDF / 供应商格式 / CSV ...)
  → 文件格式识别 / 供应商(Supplier)匹配
  → Parser / Reader 解析
  → 中间对象（原始扫描/信号）
  → 数据模型对象（Chromatogram, Signal, Scan, Peak ...）
  → 处理（Filter → Processor → Peak Detection → Integration → Identification → Quantification）
  → UI 可视化（Chromatogram View / Peak Table / Result View）
```

> 每段链路的每个跳转，都必须记录**发起方方法 → 被调方方法 → 参数 → 返回类型**。
