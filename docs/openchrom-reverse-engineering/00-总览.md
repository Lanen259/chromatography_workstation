## 0. 关键发现：双层仓库架构

OpenChrom 不是单一仓库。README 明确写道：

"It is based on ChemClipse but offers additional features that cannot be part of the ChemClipse project due to licencing constrains."

| 层 | 仓库 | 归属 | 角色 | bundle 数 |
|---|---|---|---|---|
| 核心 | eclipse-chemclipse/chemclipse | Eclipse 基金会 | 数据模型、核心算法、扩展点定义、通用 converter | ~120+（已确认 85+） |
| 扩展 | OpenChrom/openchrom | Lablicate GmbH | 受限 converter + 额外 supplier 插件 | 45（完整确认） |

移植结论：Qt/C++ 重新实现应优先吃透 ChemClipse 核心层（算法、数据模型、扩展点），OpenChrom 层为具体算法/格式供应商实现，可作参考。

## 3. Bundle 命名约定（核心解码规则）

<vendor>.<domain>.<subdomain>.<function>[.supplier.<algo>][.ui|.model]

| 段 | 取值 | 含义 |
|---|---|---|
| vendor | org.eclipse.chemclipse / net.openchrom | 所属仓库 |
| domain | chromatogram / msd / csd / wsd / vsd / fsd / nmr / pcr / model / converter / process / quantitation / report | 主功能域 |
| subdomain | msd / csd / wsd / vsd / xxd / fsd / nmr | 检测器类型 |
| function | filter / identifier / integrator / peak.detector / classifier / comparison / calculator / converter / baseline.detector / process / quantitation / report / edit | 职责 |
| supplier | firstderivative / trapezoid / peakmax / sumarea / savitzkygolay / snip / coda / denoising / massbank / nist / amdis / mz5 / cdf / gaml ... | 算法/格式供应商 |
| 后缀 | .ui / .model / .documentation | 可选 |

### 检测器类型速查
| 缩写 | 全称 | 对应中文 |
|---|---|---|
| csd | Chromatography Signal Detector | 色谱信号检测器（FID/TCD/ECD 等） |
| msd | Mass Spectrometry Detector | 质谱检测器 |
| wsd | Wavelength Signal Detector | 波长检测器（UV/Vis/PDA） |
| vsd | Vibrational Signal Detector | 振动光谱检测器（IR/Raman） |
| fsd | Flow Signal Detector | 流量信号检测器 |
| nmr | Nuclear Magnetic Resonance | 核磁共振 |
| pcr | Polymerase Chain Reaction | PCR 数据 |
| xxd | Cross-detector | 跨检测器（通用逻辑） |
