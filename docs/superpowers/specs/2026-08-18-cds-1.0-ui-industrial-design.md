# CDS 1.0 —— 工业级 UI/产品化升级设计文档（2026-08-18 自主执行）

> 目标：把已可运行的 CDS（6 模块 + MainWindow 骨架）升级为工业级、可上线的产品，UI 现代风，对标 OpenChrom 的可用性与观感（非复刻其 Eclipse RCP 架构）。
> 约束不变：契约 §4 冻结；模块间只走接口头；ui 是唯一 QtWidgets 模块；风格 §8（.ui 优先）；核心算法/模型模块**不改**（本任务只动 ui 模块 + main.cpp + 文档）。

## 1. 现状与差距

| 现状 | OpenChrom 级别 | 本次升级 |
|---|---|---|
| 单分栏布局（splitter） | 可停靠面板（Dock）+ 视图开关 | QDockWidget 工作区 |
| 裸曲线（无坐标轴/网格） | 带轴、网格、标注、概览图 | 专业色谱图控件 |
| 无主题样式 | 品牌主题（亮/暗） | 现代扁平主题 QSS |
| 方法编辑简易 | 步骤树 + 存读方法文件 | 方法 v2（JSON 存读 + 复制） |
| 无信息/日志视图 | Info/Log/Feedback 视图 | Info + Log 停靠面板 |
| 状态栏空白 | 峰值计数/范围/进度 | 实时状态信息 |
| 无持久化 | 布局/设置记忆 | QSettings |
| 启动空白 | 欢迎/演示数据 | 演示数据 + 空态引导 |

## 2. 分阶段交付

### Phase 1 —— 现代主题（`ui/resources/theme.qss` + `ui.qrc`）
- 现代扁平**暗色**主题（实验室仪器风，图表对比度好）：深灰背景、蓝青强调色、圆角控件、细边框分隔。
- 覆盖：QMainWindow / QMenuBar / QMenu / QToolBar / QStatusBar / QDockWidget / QTableView+QHeaderView / QListWidget / QPushButton / QComboBox / QLineEdit / QTabWidget / QSplitter / QToolTip / QScrollBar。
- AUTORCC 载入资源；MainWindow 构造时 `qApp->setStyleSheet`；提供 `Theme::colors()`（图表用色板，ChartPalette）。
- 测试：样式表资源存在 + 应用后控件可建不崩。

### Phase 2 —— ChromatogramView 专业版（图表重构）
- **坐标轴**：X=时间(min)、Y=强度；刻度 + 网格线；Y 轴自适应可见窗。
- **渲染**：抗锯齿折线 + 渐变填充下沿；峰标签 P1/P2 + 顶 RT（min 两位）；选区阴影。
- **交互**：左拖=选区（保留）；滚轮=以光标缩放（保留）；中键拖=平移；悬停十字线 + 提示（RT/强度）。
- **概览条**：底部细条显示全谱 + 可见窗矩形（可拖动）。
- **空态**：无数据时居中提示「导入 CSV 或加载演示数据」。
- **色板**：从 Theme 取（背景/曲线/选区/峰/网格），暗色下可读。
- 测试：轴范围 accessor、十字线命中返回 RT/强度、峰标签文本、空态绘制不崩、概览矩形拖动改可见窗。

### Phase 3 —— 可停靠工作区（MainWindow 重构）
- central = ChromatogramView；停靠面板：峰表（底部）、方法编辑器（右侧）、信息（右侧）、日志（底部）。
- View 菜单：各面板开关（toggleViewAction）。
- `saveState/restoreState` + `saveGeometry/restoreGeometry` 经 QSettings。
- MainWindow.ui 保留菜单/工具栏/动作；停靠由 addDockWidget（窗口管理，非页面布局）。
- 测试：面板创建、toggle 可见性、状态存取往返。

### Phase 4 —— 方法编辑器 v2（JSON 存读 + 增强）
- 步骤列表列：# / 显示名 / 类型 / 参数摘要；显示名来自 Registry displayName。
- 操作：Add（注册表下拉含显示名）/ Remove / MoveUp / MoveDown / Copy。
- 存读：File → 打开/保存方法（JSON：{name, steps:[{id, parameters}]}），`QJsonDocument` 往返。
- 测试：JSON 往返一致（含参数）、Copy 行为、显示名。

### Phase 5 —— 信息 + 日志视图 + 状态栏
- InfoView（.ui）：QTableWidget 两列（键/值）：名称、点数、RT 范围、scanDelay/Interval、转换器、脏标记、导入时间。
- LogView（.ui）：QTextEdit 只读，追加时间戳消息（导入/导出/管线/错误）。
- 状态栏：永久控件（峰数、RT 范围）+ 临时消息。
- MainWindow 把 import/export/run 事件写进 LogView + 刷新 InfoView。
- 测试：InfoView 填数据正确；LogView append 追加。

### Phase 6 —— 产品化收尾
- 演示数据动作（加载内置合成谱）；启动默认加载演示数据（非空界面）。
- About 对话框（版本/构建/模块清单）。
- QSettings 持久化：窗口几何、停靠状态、最后目录。
- main.cpp：High-DPI 属性、版本字符串。
- 全量构建 0 error + 全套 ctest 6/6 绿 + `--e2e` exit 0 + GUI offscreen 启动存活。

### Phase 7 —— 审查 + 合回 + push
- 独立审查子 agent 审 diff（Critical 全修）→ 合回 main → 全量验证 → push origin main → 更新看板/记忆/不确定清单。

## 3. 不改动边界（红线）
- core_model / core_processing / acq / io / report 的 include、src、tests **一行不改**（契约冻结 + 接口稳定）。
- ui 仍只 include 其他模块接口头；不改任何冻结签名。
- Method 无名称字段 → 方法 JSON 用顶层 name 字段承载（不侵入 core_model）。

## 4. 测试策略
- 全部 offscreen；新增/更新 t_ui 用例；`--e2e` 保持全链路断言（导入→管线→报告→显示）。
- 图表控件测行为 accessor（不测像素）；主题测资源加载 + 应用不崩；方法 JSON 测字节往返。
