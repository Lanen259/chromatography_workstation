## 1. 范围

- 只交付 `project/chromatography_workstation/ui/` 下的 `include/ src/ tests/ CMakeLists.txt`。
- ui 是**唯一允许 QtWidgets 的模块**；依赖 core_model/core_processing/acq/io/report 的接口头。
- **两阶段**（io 依赖兜底）：Phase A 实现视图 + SelectionController + MainWindow（不含 io 导入），Phase B 在 io(M4) 合入后补 MainWindow 的 io 导入菜单。
- offscreen 冒烟：`QT_QPA_PLATFORM=offscreen`（ctest 属性注入）。

## 2. 组件与数据流

```
Chromatogram(模型) ──setChromatogram──> ChromatogramView(自绘曲线, 缩放/平移/选区)
       │   ▲                                    │ sigSelectionRangeChanged(startMs,stopMs)
       │   │                                    ▼
       │   └──── Selection.setRange(start,stop) ──── Selection(广播 sigSelectionChanged)
       ▼
SelectionController.onChromatogramChanged ──> chrom.setDirty(true) ──> pipeline.execute(method, chrom)
       │                                                    │
       │ sigPeaksUpdated(QList<Peak>)                       ▼
       ▼                                            pipeline.peaks()/quantEntries()
PeakTableView.setPeaks(peaks)          MethodEditorView(编辑 Method.steps → sigMethodChanged)
       ▲                                                    │
       └──────────────── MainWindow(装配菜单/工具栏/分栏, 持有 Selection+Method+Pipeline)
```

- `include/ui/ChromatogramView.h`：自绘曲线控件（缩放/平移/选区），promote 进 MainWindow.ui。
- `include/ui/PeakTableView.h` + `include/ui/PeakTableModel.h`：QTableView 子类 + QAbstractTableModel 适配 QList<Peak>。
- `include/ui/MethodEditorView.h`：Method.steps 增删改（QListWidget + 按钮 + 参数表），MethodEditorView.ui 装配。
- `include/ui/SelectionController.h`：契约 §4.6 冻结签名 + 增补 setChromatogram/setMethod（open-closed，不破坏冻结项）。
- `include/ui/MainWindow.h` + `MainWindow.ui`：菜单/工具栏/分栏，持有 Selection+Method+ProcessingPipeline+SelectionController。
- `src/` 各自实现；`tests/t_ui.cpp` 冒烟。

## 3. 设计决策（非冻结处）

| 决策 | 定案 | 理由 |
|---|---|---|
| 命名空间 | 全部 `namespace cdsw`（与 core 系一致）；.ui 表单类命名 `*Ui`（如 `Ui::MainWindowUi`）避免与 C++ 类冲突 | 工程统一；`Ui::` 命名空间隔离表单类 |
| ChromatogramView | `QWidget` 自绘 paintEvent：折线取 `processedPoints()` 非空则用它否则 `signalPoints()`；滚轮缩放 X 轴、拖动平移、拖出选区矩形；`setPeaks` 画峰标记；`sigSelectionRangeChanged(qint64,qint64)` | MODULE_07 §16「图框选→写回 selection→广播」 |
| 曲线数据源 | `setChromatogram(Chromatogram*)` 只存指针不拷贝，视图重绘时读 | 对齐模型指针语义 |
| PeakTableModel | 列：Peak # / Apex RT (min) / Start RT (min) / Stop RT (min) / Height / Area（与 report 峰表列一致）；`setPeaks` 数据驱动；RT 分钟定点 `'f',6` | 与 M5 report 报告格式同源，减少心智负担 |
| MethodEditorView | `.ui` 装配：QListWidget（步骤 id 列表）+ 工具按钮（Add from registry / Remove / MoveUp / MoveDown）+ QTableWidget 参数 k/v 编辑；`setMethod(Method*)`、`method()`、`sigMethodChanged()`；Add 从 `Registry::availableFilterIds()/availablePeakDetectorIds()/availableIntegratorIds()/availableQuantifierIds()/availableBaselineIds()` 合并供选 | MODULE_07 §10 步骤树 + §7 Qt 移植 |
| SelectionController | 契约构造 `(Selection*, ProcessingPipeline*, QObject*)`；增补 `setChromatogram(Chromatogram*)` `setMethod(const Method*)`；`onChromatogramChanged` → chrom->setDirty(true) → pipeline->execute(*method,*chrom) → `emit sigPeaksUpdated(pipeline->peaks())`；空 chrom/method 时安全跳过 | 契约 §4.6 握手语义；execute 需 chrom+method，故增补 setter |
| MainWindow | `.ui` 装配：menuBar(File/Processing/Report/Help) + toolbar + central QSplitter(左 ChromatogramView 横向、右 QSplitter 纵向 PeakTableView+MethodEditorView)；持有 `Chromatogram m_chrom`、`Method m_method`、`Selection m_selection`、`ProcessingPipeline m_pipeline`、`SelectionController m_controller`；菜单：Import(Phase B 用 io)/Run Method/Export CSV Report(用 report ReportRegistry)/Quit | MODULE_07 §13 e4→QMainWindow |
| .ui 文件 | `MainWindow.ui`、`MethodEditorView.ui` 进 `target_sources(ui ...)`（cdsw_add_module 不 glob .ui，需手动加，AUTOUIC 生成 `ui_*.h`）；ChromatogramView/PeakTableView 以 promote 占位进 MainWindow.ui | 风格 §8：复用页面 .ui、自绘控件 promote |
| 测试 | `t_ui.cpp` 用 `QTEST_MAIN`（QApplication 必需）；`set_tests_properties(ui_tests ENVIRONMENT "QT_QPA_PLATFORM=offscreen")` | 无头冒烟 |
| SelectionController 冒烟 | 构造真实 `ProcessingPipeline(Registry::instance())` + Method（含 `first_derivative_peak_detector` 步骤）+ 合成峰信号 Chromatogram → onChromatogramChanged → sigPeaksUpdated 非空 | 验证真实链 |

## 4. 测试计划（offscreen 冒烟）

1. **ChromatogramViewTest**：setChromatogram(带信号点) → 控件可创建、paintEvent 不崩；模拟滚轮/拖拽 → sigSelectionRangeChanged 发出且范围合理；setPeaks 后重绘不崩。
2. **PeakTableModelTest**：setPeaks(固定峰) → rowCount/columnCount/data(Peak #/RT/Height/Area) 正确；空列表 → 0 行。
3. **MethodEditorViewTest**：setMethod(带 steps) → 列表项数正确；Add(注册表 id) → method steps +1；Remove/MoveUp → 顺序正确；编辑参数 → 写回 QVariantMap；sigMethodChanged 触发。
4. **SelectionControllerTest**：真实 pipeline + 峰检测方法 + 合成色谱 → onChromatogramChanged → sigPeaksUpdated 收到非空峰列表。
5. **MainWindowTest（Phase A）**：offscreen 创建 MainWindow 不崩、菜单存在；setChromatogram 后视图不崩。（Phase B 补 Import 冒烟。）
